Mod Selection Select matching replaces the selection with mods whose paths contain the entered text. An empty path matches all mods; required mods exclude \optionals\. Toggle all selects or clears a category based on its first mod.

Presets Apply a predefined modpack to quickly configure the server with a set of mods.
